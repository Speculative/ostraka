# v0.5.0 release notes

Ostraka now includes a responsive web workspace for desktop and mobile
browsers. It shares project state and agent dispatch with the CLI and TUI.

## Changes since v0.4.0

- Browse conversations, manage items and project context, and compose turns
  with Markdown previews and syntax highlighting.
- Receive live project and agent trace updates, with shared drafts across
  the TUI and multiple browser clients.
- Review changes with side-by-side diffs, mouse and touch line selection,
  inline comments, and item-targeted reviews.
- Use the new design system and compact mobile layout. Inbox ordering now
  matches the TUI; Archive shows the most recently active families first.
- Serve the web workspace behind an authenticated reverse proxy without
  configuring a public hostname in Ostraka. Browser writes retain origin
  checks, and rendered Markdown is sanitized.
- Inspect the installed release with `ostraka version`.
- Improve TUI selection retention, review recovery and routing, occupied
  goal-mode handling, and Ctrl+C targeting.

## Install and run

Install with Go 1.26.5 or newer:

```sh
go install github.com/Speculative/ostraka/cmd/ostraka@v0.5.0
ostraka version
```

From an initialized project, run the web workspace alongside a running TUI:

```sh
ostraka web
```

For a web-only session, close the TUI and let the web server own dispatch:

```sh
ostraka web --supervise
```

The default listener is `127.0.0.1:8090`. Remote access requires a trusted
network or an authenticated reverse proxy; Ostraka has no built-in login.
Preserve the public Host and browser Origin and pass `/api/events` through
without buffering. Public `*.agents.speculative.tech` hostnames require no
special Ostraka setting. See [web deployment](../web.md) for details.

## Release validation

The full Go suite passed against the committed release candidate plus the
module metadata cleanup. Existing web smoke, ordering, and desktop/mobile
Chromium checks passed during implementation. The user reports successful
remote access through frp at `ostraka.tunnel.speculative.tech`.

The automated Lyoko proxy path has not been exercised. A real provider turn
with live streaming and phone background/resume/reconnect remain explicit
deployment checks; the frp report does not establish those individual results.

See [the release procedure](../deploying.md#publish-a-release) for publication
and Go module proxy indexing.
